# HamStation Mobile

Rig control, logger, POTA and DX cluster spots for Android, by K0BF.

## Installing it on your phone or tablet

HamStation Mobile isn't in the Play Store, so it's installed from this page ("sideloaded").
It only takes a minute, and you only do it once: after that the app updates itself.

1. **Download.** On the phone, open this page in Chrome, tap the `HamStation-Mobile-….apk` file
   in the list at the top, then tap **Download** (or **View raw**). Chrome may ask
   "Download file anyway?": tap **Download**.
2. **Open it.** Tap the download notification, or open **Files → Downloads** and tap the APK.
3. **Allow the install.** The first time, Android says the phone "isn't allowed to install unknown
   apps from this source". Tap **Settings**, turn on **Allow from this source**, then go back.
4. **Install.** Tap **Install**. If Google Play Protect warns about an unknown app, tap
   **More details → Install anyway** (it warns about anything not from the Play Store).
5. **Open HamStation** and fill in your callsign in **Setup**.

**Amazon Fire tablets:** before step 2, go to **Settings → Security & Privacy → Apps from Unknown
Sources** and turn on **Silk Browser** (or **Files**, whichever you open the APK with).

## Hooking up the radio

Plug the radio's USB cable into the phone with a USB OTG cable or adapter (USB-C or micro-USB to
USB-A). When Android asks to let HamStation use the USB device, tick **Always** and tap **OK**,
then pick the radio in **Setup**.

## Updates

No need to download again: **Setup → App updates → Check for update**, then **Install**.
